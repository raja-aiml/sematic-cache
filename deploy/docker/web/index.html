🚀 Semantic Cache

High-performance semantic caching system for AI applications

Docker Deployment

🔗 API Endpoints

Health Check: GET /semantic-cache/health

Metrics: GET /semantic-cache/metrics

Set Cache: POST /semantic-cache/set

Get Cache: POST /semantic-cache/get

Query: POST /semantic-cache/query

🧪 Quick Test

Test the API with curl:

# Check health
curl http://localhost:8080/semantic-cache/health

# Set cache entry
curl -X POST http://localhost:8080/semantic-cache/set \
  -H "Content-Type: application/json" \
  -d '{"prompt": "What is AI?", "answer": "Artificial Intelligence"}'

# Get cache entry
curl -X POST http://localhost:8080/semantic-cache/get \
  -H "Content-Type: application/json" \
  -d '{"prompt": "What is AI?"}'
